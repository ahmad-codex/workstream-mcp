# Getting help

- **How do I ...? / Is this a good fit for ...?** Start a thread in
  [GitHub Discussions](https://github.com/ahmad-codex/workstream-mcp/discussions) (Q&A category).
- **Something is broken.** Open a [bug report](https://github.com/ahmad-codex/workstream-mcp/issues/new/choose).
  Include the commit or version, how you run it, and the failing tool call or request.
- **A security problem.** Do not open an issue. Follow [SECURITY.md](./SECURITY.md).

Before asking, check the [docs](./docs) and the [spec](./workstream-mcp-spec.md); most
behavior questions are answered there.

Never paste an MCP URL: the token in it is a credential. Replace it with `<token>`.

This is a project maintained in spare time. There is no paid support and no response-time
guarantee; issues with a clear reproduction get answered first.
